# Early Prediction of Chronic Kidney Disease Using Machine Learning

## Overview
This project focuses on the early prediction of Chronic Kidney Disease (CKD) using Machine Learning techniques. The system analyzes medical and clinical data to identify patterns associated with kidney disease and predicts the likelihood of CKD at an early stage.

The main objective of the project is to assist healthcare professionals in early diagnosis and improve patient outcomes through AI-powered predictive analysis.



## Features
- Early CKD prediction
- Medical data preprocessing
- Feature selection and analysis
- Multiple Machine Learning models
- Performance evaluation using accuracy and F1-score
- Healthcare-oriented predictive system
